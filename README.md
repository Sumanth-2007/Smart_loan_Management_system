PROJECT TITLE:-
                SmartLoan: Rule-Based Loan Eligibility & EMI Evaluation System


## PROJECT DESCRIPTION: 

The Smart Loan System is a Java-based console application designed to manage customer information and loan processing efficiently. It allows users to add customers, check loan eligibility,check maximum loan amount possible, apply for loans, and calculate EMI. The system demonstrates core programming concepts such as Object-Oriented Programming, exception handling, and data management. It ensures proper handling of invalid inputs and maintains records of loan applications. The application simulates real-world loan approval systems using basic programming concepts.

-----------------


## JAVA CONCEPTS USED:

* Object-Oriented Programming (OOP)
  * Inheritance
  * Encapsulation
  * Abstraction
* Arrays for data storage
* Exception Handling (custom exceptions)
* String Handling (search functionality)
* Control Statements and Loops
* Packages

-----------------


## HOW TO COMPILE & RUN THE PROJECT:

Step 1: Compile

From Project Root: javac -d out src/app/Main.java src/service/*.java src/model/*.java

Step 2: Run

java -cp out app.Main

-----------------

## SAMPLE WORKFLOW:

1. Add a new customer
2. Search for the customer
3. Check maximum loan amount possible for the customer(based on income)
4. Check loan eligibility
5. Apply for a loan
6. Calculate EMI
7. View applications
8. View Summary

-----------------

## KEY HIGHLIGHTS:
